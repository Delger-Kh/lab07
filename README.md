## Хэсэг E: Дүгнэлт (debrief)

Saboteur аялалаар curl ашиглан буруу JSON илгээхэд сервер 400-ын оронд 200 OK буцаасан (BUG-05), мөн хоосон {} болон 3000 онтой номыг API хүлээн авч хадгалсан нь шалгалт серверт ч байхгүйг харуулсан. Supermodel аялалын үеэр «Хуучин хувилбар» линк Internal Server Error өгч байгааг олсон (BUG-06), Fed-Ex аялалаар хайлт том/жижиг үсэг ялгадгийг илрүүлсэн (BUG-07). Charter-аас гадуур санамсаргүй ажигласан зүйл нь хайлт хийсний дараа ч «Ном нэмэгдлээ» мессеж хэвээр үлдэж, үйлдэлдээ тохирохгүй байсан явдал юм. Цаг дутсан тул Устгах товчны өнгө, мессежүүдийн үсгийн алдаа, 300 тэмдэгттэй урт оролт, давхардсан ном нэмэх, устгасны дараах тоолуурыг шалгаж амжаагүй бөгөөд эдгээр нь дараагийн session-ий charter болно. Лаб 1-ийн Playwright автомат тест тодорхой assertion бичсэн тохиолдолд хоосон талбар, Оны хязгаар, тоолуурын зөрүү, API-ийн статус код, /old хуудасны 500 алдаа, хайлтын үр дүнг (BUG-01, 02, 04, 05, 06, 07) барих байсан. Харин Он «1,971» гэж таслалтай харагдах (BUG-03), товчны өнгө, мессеж үйлдэлдээ тохирох эсэх зэргийг хүний нүд илүү амархан анзаардаг, учир нь ийм зүйлийг шалгах assertion-ийг урьдчилан бичих нь ховор. Энэ session-оос авсан хамгийн том сургамж бол туршилт бүрийн дараа шууд цагтай тэмдэглэл бичих хэрэгтэй гэдэг байлаа.
